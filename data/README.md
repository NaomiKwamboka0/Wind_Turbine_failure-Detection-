# Data

Put `wind_turbine_detection.csv` here, or next to the notebook you are running (the notebooks read it from their own folder).

The file came with the course and is not stored in this repo. It has 131,760 rows and 35 columns: 10-minute readings from 15 turbines between 1 January and 1 March 2024, with `failure` (0 = normal, 1 = fault) as the column to predict.
